基线标签：`r3-native-ui-baseline-20260920`。

## 冻结范围

- 稳定单屏、P1/R1、R2 和 R3 的现有源码、启动器、测试及文档。
- 已安装适配二进制：单屏输入 agent/SDL shim、R3 agent/双屏 shim。
  精确字节随 Git 保存，不依赖重新打包 JAR 时的时间戳。

  正是用户反馈“下屏远景缺失、4.3 寸元素偏小”的修改前状态，不把这些问题说成已修复。

不上传正版/派生游戏 JAR、游戏资源、截图、存档、偏好、设备日志或凭据。
本地 `validation/` 证据保留，仓库文档仅索引它们。私人仓库不是公开发行包。

## 回退方式

优先另建工作树查看基线，保留当前修改，不使用 `reset --hard`：

```powershell
git worktree add --detach "..\SlayTheSpire-R3-baseline" r3-native-ui-baseline-20260920
```

只需恢复设备上的 R3 时，从该工作树取 R3 的两个二进制、supervisor、touch_bridge、
以及对应启动器；沿用基线的单屏输入 agent 和 P1 触摸模块。
先关闭测试游戏并确认自有进程退出，不覆盖 `saves/`、`betaPreferences/` 和正版 JAR。
现有 `prototype/r3/device.py deploy` 是固定私有设备部署工具，
依赖同设备既有隔离目录和 `/tmp/rgds-sts-silent-01`，不是通用干净安装器。
若该临时源已不存在，应单独恢复适配文件，不能为回退去覆盖正式玩家数据。

从新机器重建时需用户自行提供正版 JAR、固定上游依赖、JDK 和 ARM64 编译器；
路径说明见 `README.md`、`prototype/r3/README.md`。

## 下一轮修改边界

1. 下屏使用完整无角色背景：底图、远景/场景层、原生前景；
   上屏保留底图与远景及角色战斗，不显示装饰前景。
2. 背景复用只作用于渲染，不能重复推进动画、规则或场景状态。
3. 4.3 寸可读性不等于改变游戏逻辑分辨率；优先增大关键信息、选中卡牌和控件，
   同步处理 hitbox、焦点导航和逆坐标，避免只放大绘图导致点不中。
4. 保持稳定单屏、独立退出、按键兜底和隔离存档。字体/多牌/弹窗/目标箭头分别回归。
5. 后续工作在 `codex/` 开发分支开展；冻结标签不移动、不覆盖。
