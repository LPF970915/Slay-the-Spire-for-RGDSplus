# Slay the Spire for RGDSplus 20260924-02

离线依赖完整包，不包含游戏本体、玩家存档、缓存或日志。

## 安装不变

1. 将压缩包中的整个 `Ports` 文件夹合并到卡二根目录。
2. 把正版 `desktop-1.0.jar` 放入
   `Ports/Slay the Spire for RGDSplus/`。
3. 从 Ports 菜单启动同名游戏。

无需联网，也无需另开 PortMaster 下载 Java 或 Weston。
旧版用户完整覆盖适配文件即可，保留正版 JAR、存档和已生成的缓存。

## 本轮改动

- 内置固定上游版本的 ARM64 Java 17 和 Weston SquashFS 镜像。
- 优先使用游戏目录内的离线镜像，只读挂载，不覆盖共享 PortMaster。
- 启动时显示离线运行库校验提示，检查 SHA-256、可挂载性和 Java 实际运行。
- 文件缺失、复制不完整或损坏时，在解压游戏资源前显示错误并保存日志。
- 清除启动器中对另一个移植应用库目录的引用。
- 补齐独立的 ARM64 `libjpeg.so.8` 和 `libXtst.so.6`，避免此前借用
  阅读器应用或 PortMaster 的共享库；校验 Weston 后端和 Xwayland 的动态依赖。
- 保留之前的双屏布局、触摸链路、资源释放、缓存和会话恢复逻辑。

## 适用范围

包内补齐的是游戏额外需要的 Java/Weston 运行库，不是整套固件。
仍需兼容的 RGDSplus ARM64 Linux/Wayland 固件、固件自带 PortMaster
输入工具、Python 3、系统音频库与驱动。不能承诺损坏的卡、复制不完整、
不兼容的固件或不同游戏 JAR 均可成功安装。

## 本地检查

- 工具测试 94 项、P1 测试 34 项通过；触摸契约检查通过。
- 镜像与固定 PortMaster Git blob、文件长度和 SquashFS 标头一致。
- ZIP 中全部载荷校验通过；无正版/衍生游戏 JAR、玩家数据或凭据。
- 离线镜像的来源及许可证说明在包内 `NOTICES/`，镜像自身通知完整保留。

## RGDSplus 实机验证（2026-09-24）

- 使用独立卡二测试目录，只放正式包载荷及用户本机正版 JAR，不带预热缓存、
  已补丁游戏 JAR 或存档。最终实机载荷逐文件匹配发布包清单。
- 在私有挂载命名空间隐藏共享 PortMaster `libs/`，在私有网络命名空间
  仅启用本地回环接口；没有外网接口、没有联网下载运行库。
- 全新安装处理 432 个音频文件，生成并校验补丁 JAR，再生成纹理缓存；
  成功到达双屏新建存档界面，预热完成，帧计数持续增加。
- 再次启动复用缓存，不再执行资源解压；双屏画面正常出现。
- 两次验证中触摸软件通道连接、取得焦点、捕获设备成功；
  本轮没有实体触摸操作验收，不据此宣称所有交互问题均已解决。
- 音频引擎保持启用，测试期间仅暂时静音系统输出；
  最后恢复原静音状态，未调整音量数值。
- 正常通过会话监管器结束，恢复触摸模式和掌机菜单。独立测试目录已清理，
  没有临时镜像挂载残留，用户正式安装、存档、缓存和共享运行库未修改。

首次隔离验证额外揭示了过去对阅读器目录 `libjpeg.so.8` 和共享
`libXtst.so.6` 的隐式依赖，最终包已经包含固定来源的独立副本。

最终空缓存安装和重启使用修正后的隔离环境，通信已正常连接。

这些结果验证了当前兼容固件上的离线安装与重启路径，
不能代替不同固件、所有游戏 JAR、损坏存储卡或游戏全流程的验收。
