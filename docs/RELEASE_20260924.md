# Slay the Spire for RGDSplus 20260924-01

本包仅包含适配器，不包含游戏本体、运行镜像、个人存档或玩家日志。

## 针对性修复

- Java 17、Weston、PortMaster 输入工具和必要系统依赖在资源释放之前检查，
  无论冷安装还是已存在缓存的后续启动都会执行。
- Java 镜像临时只读挂载后实际运行 `java -version`，有超时限制；
  Weston 镜像检查可挂载性及入口脚本。独立检查挂载在退出时释放。
- 失败原因写入 `.preflight.txt`，Java 检查输出写入 `.java-check.txt`。
  固件显示服务与终端可用时，错误提示保留约 45 秒。
- 保留游戏 JAR、缓存和存档，不自动下载或修改系统依赖。

## 依赖与更新

PortMaster 的 `libs/` 目录需要以下镜像：

```text
zulu17.54.21-ca-jre17.0.13-linux.squashfs
weston_pkg_0.2.squashfs
```

这些镜像需通过 PortMaster 另行安装，不包含在本适配包内。
先退出游戏并备份存档，再合并覆盖适配文件。必须同时复制新的
`runtime_preflight.sh`，不要只替换启动脚本。若旧版已经释放完资源但报
`Java 17 runtime not found`，补齐 Java 后可复用缓存，无需重新释放资源。

## 验证边界

收到的失败案例在资源生成并校验完成后因找不到 Java 17 返回 3，
后续启动复用缓存后仍返回 3。这个案例不是游戏 JVM 内部崩溃，
也不证明其他玩家的失败都具有同一原因。原始玩家日志不随仓库发布。
日志中的设备时钟显示 2017 年，而固件构建日期为 2026 年，不能把日志
文件名当作实际故障日期。

依赖预检不能代替实际游戏启动、完整图形驱动兼容性、实体触控或全流程验收。

本轮 17 项预检测试覆盖缺失依赖、Java 无法运行/版本错误、镜像挂载失败、
临时挂载回收和提示内容。RGDSplus 隔离检查中，现有 Java 17 与 Weston 镜像
通过；模拟缺少 Java 时在资源释放前失败，无检查挂载残留。
隔离检查未启动游戏、未改动存档/资源缓存，未测量实体屏幕提示效果。
