# Slay the Spire for RGDSplus 20260923-14

本 Release 仅含适配包，不包含《杀戮尖塔》游戏本体、正版
`desktop-1.0.jar`、存档、缓存、日志或完整测试包。

## 本版内容

- 固化正式项目名：`Slay the Spire for RGDSplus`。
- 修复事件触发战斗时沿用单屏手牌缩放的问题，改用普通战斗的双屏扇形手牌布局。
- 保留商人、教程、奖励、事件、地图和战斗的双屏路由修订。
- 保留资源释放阶段的提示、进度计数、心跳和纹理缓存复用。
- 清理公开仓库中的私有交接、设备信息、实机证据和历史私有适配包工具。
- 增加公开载荷审计，拒绝游戏本体、存档、缓存、日志、凭据和设备内部地址。

## 安装

1. 退出游戏并备份整个 `saves/`。
2. 下载 `Slay the Spire for RGDSplus.zip`，解压并合并卡二的 `Ports/`。
3. 将自己合法取得的正版 `desktop-1.0.jar` 放入
   `Ports/Slay the Spire for RGDSplus/`。
4. 启动 `Slay the Spire for RGDSplus`。

首次释放资源期间请勿关机或拔卡。后续启动会复用已完成的补丁和纹理缓存。

## 验收边界

静态构建、触摸契约、P1 输入回归、R4 路由/战斗回归和适配包审计已通过。
这些测试不等同于所有设备上的实体触摸精度、全流程通关或长期稳定性验收。
