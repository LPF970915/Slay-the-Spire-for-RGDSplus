# R3 真实游戏双屏 UI 接入

日期：2026-09-20。阶段结论：真实 UI 已接入，供远程审图；不是双屏交付验收通过。
用户离开设备后明确授权继续到真实 UI 和截图，因此允许隔离推进 R3。
R2 的实体九点/边缘误差、实体屏序、30 分钟验证仍保留待验，不以此次授权抵销。

## 1. 隔离边界

- 卡二目录：`/mnt/sdcard/Ports/SlayTheSpireDualR3`。
- 菜单入口：`Slay the Spire R3 Native UI.sh`，默认 1,200 秒有限会话。
- 使用早期静音测试副本的游戏、偏好和存档，不读取正式玩家存档进行游玩。
- 正式单屏、R1 和 R2 入口不替换。正版 JAR 仅在本地及用户设备私有测试目录。
- Java agent、SDL shim 源码不含游戏素材；运行时路由绘制，不原位修改正版 JAR。
- 游戏内部禁用音频，不修改系统音量。中文只设置在 R3 私有偏好中。
- 退出保留独立长按 Select；按进程身份清理自有会话，恢复菜单和已知触摸模式。

## 3. 渲染与输入实现

1. 同一游戏帧只执行一次原生 update，不复制整套战斗渲染或推进两次动画。
2. 在原生绘制调用边界切换 viewport，保存/恢复 SpriteBatch 投影和变换。
3. 手持卡牌的布局变换放进投影矩阵。原生 FontHelper 会重设旋转文字的变换矩阵；
   早期版本因此出现卡面与标题/描述错位，本轮已修复并重新截图。
4. 下屏背景取原生 scene 的底层图集区域，装饰前景只向下屏绘制；
   上屏保留战斗地面，不把战场裁成漂浮角色。
5. 选敌虚线的端点来自原生 `hoveredMonster`，上屏高亮也使用原生选敌状态。
   目前由手柄驱动，不是触摸方向拖牌已经接入。
6. 复用 touch2 原版 `touch_mode.py`、`device_input.py`，显式启用及条件恢复 tpctrl。
7. SDL 状态在创建视频窗口的同一线程补充 PumpEvents。焦点心跳用单调时钟写入内容，
   不使用卡二文件修改时间：实测文件时间精度会让 1.5 秒失效判断反复释放/抢占触摸。
8. 触摸桥明确为 `capture-only`。当前只采集、获焦独占、失焦取消，不向 Java 提交点击或出牌。
   真实 hitbox 逆变换、方向选敌和松手提交仍需下一轮实现。
   获焦时先取消旧手势，再由 `set_focus` 重同步；不得在重同步后再取消，
   否则会覆盖空闲状态并吞掉首次点击。本轮注入发现并修复了这一接线顺序。
9. 原生启动链不继承探针锁 fd，防止 PortMaster 残留辅助进程阻止再次启动；
   监护和触摸进程仍持锁，避免恢复期间启动另一探针。

## 4. 实测证据与边界

输入来源为远程 evdev 软件注入；不是用户实体按键或触控笔验收。

- 原生选牌、左右选敌、确认出牌：打击 1 张，右侧敌人 14→8 血，左侧仍 12 血；
  能量 3→2，手牌 5→4，弃牌 0→1。取消后未再扣费；抽牌和弃牌页面可打开/返回。
- 原生游戏状态与双屏状态四份截图采样均为 frames=updates。
  这不等于已覆盖随机种子、所有动作与 200 次规则提交对照。
- 独立 Select 长按 2 秒软件注入已触发退出，三个探针锁释放；
  退出后只剩系统 Weston 和已恢复菜单，无本次 Java/gptokeyb/portsCtrl。
- 正式单屏两个适配二进制和正式铁卫存档 SHA-256 与测试前一致。
- 最终触摸采集复测：菜单、战斗各注入 1 次点击，共 4 个 down/up 动作；
  首次点击不再丢失，战斗能量/手牌/弃牌/HP 不变。实体准确性和真实点击提交未验。
- 最终 300 秒有限会话已自动退出，`audit-1789885888526641457.json`
  确认菜单为运行态、三个锁均空闲、tpctrl 恢复为 0、无残留测试游戏。
  最后的长按复测请求因 JVM 已自动退出被保护检查拒绝，未向菜单注入按键；
  长按成功证据来自前面的 889 秒会话，不能混记为最后一次实测。
- `frames-23671.csv` 全段：约 889 秒，21,208 个非抓图邻接间隔；
  平均 23.36 FPS，P95 43.735 ms、P99 46.037 ms，最长 19,243.207 ms。
  最长停顿发生在启动加载，不能从全段报告中删掉。
- 从最终战斗布局截图到该次会话末尾：约 677 秒，16,237 个间隔，
  平均 24.00 FPS，P95 43.687 ms、P99 45.995 ms，最长 90.489 ms，
  大于 100 ms 为 0。只排除抓图前后间隔，不排除其他慢帧。
- 这不是 30 分钟或 2 小时长稳。静音不能证明音频稳定，帧缓冲不能证明实体面板无撕裂。

## 6. 下一步与门槛

1. 用户远程确认上下屏构图，尤其手牌大小/高度、下屏前景遮挡及目标虚线。
2. 接入真实 hitbox 逆变换与输入 owner，保留原生手柄；不能把触摸采集成功当成点击成功。
3. 方向拖牌沿用 R1 的扩大上抛区、目标保持、取消和快速释放规则；
   目标身份与原生规则一致，先完成受控 200 次出牌/取消。
4. 验证地图、奖励、商店、事件、营火、升级/删牌、弹窗、药水与顶栏焦点；
   尤其卡牌特效目标坐标、提示层归属与大手牌布局，当前尚未全部适配。
5. 补 R2 实触、实体视频、冻结时退出、30 分钟以及正式长稳；
   焦点过期应释放触摸，不能为了“看似能触摸”放宽成后台永久独占。
6. 公开交付仍使用无游戏资源适配包 + 用户手动放入正版文件，
   不包含本次私有游戏副本、截图、日志、偏好或存档。
