# 《杀戮尖塔》RGDSplus 单屏适配包

这是不含游戏本体的适配包。需要用户拥有 Steam 正版，并手动复制：

```text
desktop-1.0.jar
```

将它放到设备：

```text
/mnt/sdcard/Ports/SlayTheSpire/desktop-1.0.jar
```

不要复制 Windows `SlayTheSpire.exe`、Windows `jre/`、`mod-uploader.jar`
或 `mts-launcher.jar`。本包使用 PortMaster 提供的 aarch64 Java 17 运行时。

首次启动会在 `cache/builds/` 下生成补丁 JAR。上游提示首次补丁可能约需
15 分钟；原始 `desktop-1.0.jar` 会保留，失败时不会替换它。补丁完成后，
缓存目录出现 `ready.txt` 才会启动游戏。

P0 仍是单屏 1024x768 版本：使用 PortMaster Weston wrapper runtime
提供 XWayland/GL4ES 兼容层，游戏的 SDL 窗口直接连接系统 Wayland。
会记录实际 Java PID、退出码、资源采样和崩溃尾日志。
不修改触摸固件模式，也不启用双屏布局。
采用原游戏原生 4:3 分支，不拉伸 16:9 画面。修正 ASTC 压缩输入的
RGB/RGBA 字节步长与缓冲区偏移，禁止把不透明 RGBA 再错误降为 RGB。
短边小于 128 像素的小图集保留非压缩上传，避开已复现条纹的 ETC2 回退路径。
有风险的旧纹理使用新缓存键重建；首次遇到相关场景时加载可能较慢。
当前只完成局部显示验证，不代表全部战斗、物理屏幕撕裂与长稳验收通过。
SSH 启动测试时会临时暂停仍在运行的系统菜单，避免 A 键同时触发菜单；
退出游戏会恢复菜单，系统 Weston 和音频服务不会被停止。

## 按键与应急退出

使用小丑牌已验证的 RGDSplus SDL 手柄布局，通过 PortMaster `gptokeyb`
接到游戏原有虚拟手柄。方向键/左摇杆负责导航，A 确认、B 取消；
X/Y、L1/R1、L2/R2、Start、Select 送入对应的游戏手柄操作，
具体功能随游戏页面提示变化。方向与扳机不共用键码。
L2 打开抽牌堆、R2 打开弃牌堆，B 返回；对应牌堆为空时由游戏原生逻辑处理。
短按的按下/松开即使落在同一轮轮询中，也会保留至少一帧；
积压最多保留两次，切换输入处理器时丢弃未处理的积压，避免加载后连点。

新建存档时自动预填 `RGDS 1`、`RGDS 2`、`RGDS 3`，无需实体键盘：
命名弹窗用 Y 确认、B 取消。已有存档的命名弹窗保留原名称。
当前版本没有完整屏幕键盘，X/L/R 等映射按键不会写入存档名称。
打开或关闭命名框后，手柄输入会继续生效。

长按 Back/Select、Guide 或独立返回键约 1.5 秒触发应急退出。
独立 Python 3 进程监听按钮，不依赖 Java 渲染线程；
先向本次游戏进程发送 TERM，3 秒后仍未结束才发送 KILL。
正常退出请使用游戏菜单，应急退出不保证保存尚未存盘的进度。
本功能需要固件 Python 3，以及 PortMaster 的 `gptokeyb`。

该显示兼容层在本固件下曾出现约 1 秒一次的换帧等待，导致游戏跳过逻辑
和输入更新。本包只在此游戏进程内将 Crusty 的 SDL swap interval 设为 0，
保留游戏本身的 24 FPS 上限；不修改系统 Weston 的全局设置。

运行日志位于：

```text
/mnt/sdcard/Ports/SlayTheSpire/logs/
```

建议安装在空间充足的卡二。当前私有测试机的卡一启动入口已转发到卡二，
游戏文件、存档与缓存均从卡二读取；卡一原目录暂作备份。更新适配包时
不需要重复上传正版 JAR。构建过程中只读取正版原文件。
包内显示默认值同样为 1024x768/24 FPS；`CHECKSUMS.sha256` 校验适配文件，
不包含游戏和启动器会改写的 `info.displayconfig`。

需要验证的流程是：标题、音频、战斗、地图、商店、事件、营火、奖励、
首领、保存、退出和读档。首次验证请使用独立测试存档，避免覆盖主存档。
